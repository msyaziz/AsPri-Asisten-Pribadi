# Asisten Pribadi Self-Hosted
Bot WhatsApp + Web Dashboard (STB HG680p, Node.js, PostgreSQL, Groq).

Mulai dari `docs/00-konteks-aplikasi.md`, lalu kerjakan fase sesuai `docs/01-...` dan seterusnya.

## Perintah
    npm install          # pasang dependensi (lihat docs/01 bagian 6)
    npm run migrate      # jalankan migrasi SQL
    npm start            # jalankan (atau pakai PM2: pm2 start ecosystem.config.cjs)
